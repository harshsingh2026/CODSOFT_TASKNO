# 🚀 CodSoft Python Internship

This repository contains the Python projects completed for the **CodSoft Python Programming Internship**.

## 📂 Projects Included

### ✅ Task 1 – To-Do List

A simple command-line application to:

* Add tasks
* View tasks
* Delete tasks
* Exit the application

**File:** `todo.py`

---

### ✅ Task 2 – Calculator

A basic calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

**File:** `calculator.py`

---

### ✅ Task 4 – Rock Paper Scissors Game

A fun command-line game where the user plays against the computer.

**Features:**

* User vs Computer
* Random computer choice
* Win / Lose / Draw result
* Play again option

**File:** `rock_paper_scissors.py`

---

### ✅ Task 5 – Contact Book

A contact management system that supports:

* Add Contact
* View Contacts
* Search Contact
* Update Contact
* Delete Contact

**File:** `contact_book.py`
